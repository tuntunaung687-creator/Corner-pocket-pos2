CORNER POCKET POS - 15 TABLE OFFLINE PROTOTYPE

အသုံးပြုနည်း
1. ZIP ကို ဖြည်ပါ။
2. index.html ကို Android Tablet ရဲ့ Chrome သို့မဟုတ် အခြား Browser နဲ့ဖွင့်ပါ။
3. Internet မလိုပါ။ ဒေတာကို အဲဒီ Browser ရဲ့ Local Storage ထဲမှာ သိမ်းပါတယ်။
4. Settings ကိုဖွင့်ရန် မူလ Owner PIN = 1234
5. ခုံ ၁၅ ခုံလုံးကို Settings မှာ အသေး/အကြီး သတ်မှတ်နိုင်ပါတယ်။
6. Settings ထဲက Backup ထုတ်ရန်ကို မကြာခဏ အသုံးပြုပါ။

ပါဝင်သော Prototype လုပ်ဆောင်ချက်များ
- 15 tables, open/close only (Pause မပါ)
- Owner PIN ဖြင့် table close
- Table transfer
- Small/Large hourly rates (default 9,500 / 12,000 Ks)
- Marker fee (default 900 Ks/hour; marker မရွေးလျှင် မကောက်)
- Staff / marker list
- Food items and sales
- Daily date-filtered summary and bill history
- Print dialog for bill
- Backup export/import

အရေးကြီး
ဤဖိုင်သည် Offline HTML Prototype ဖြစ်ပြီး Android APK မဟုတ်သေးပါ။
ခုံပိတ်ခြင်း၊ အရောင်းနှင့် စာရင်းတွက်ချက်မှုကို စမ်းသပ်ရန် ရည်ရွယ်ထားသည်။
ဝန်ထမ်းတစ်ဦးချင်း login/permission, audit log, ပယ်ဖျက်မှုမှတ်တမ်း၊ လစဉ်/နှစ်စဉ် report တို့သည်
နောက်တစ်ဆင့်တွင် ထပ်မံတည်ဆောက်ရန် လိုအပ်သည်။
Browser data ကို clear လုပ်လျှင် ဒေတာပျောက်နိုင်သဖြင့် Backup ထုတ်ထားပါ။
